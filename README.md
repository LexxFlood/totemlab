# TotemLab

Projeto editável. Leia CONTINUE-AQUI.md. A versão atual está em dist. Execute `python -m http.server 8000 --directory dist` para testar.

O workflow Pages publica dist a cada push em main quando GitHub Pages estiver habilitado com origem GitHub Actions. Colaboradores Write podem enviar alterações.

Publicação em GitHub Pages não altera automaticamente o endereço chatgpt.site original, vinculado ao proprietário no Sites.

Não execute build-site.py sem revisar: melhorias recentes estão diretamente em dist. Nunca adicione tokens ao repositório.
